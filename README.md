📊 Business Performance Analysis using SQL  
📌 Project Overview

This project focuses on analyzing business performance data using MySQL.
The goal is to derive meaningful business insights such as top-performing projects, revenue contribution, regional growth trends, and performance categorization using advanced SQL concepts.

The project is designed to demonstrate real-world SQL skills suitable for data analyst / business analyst roles.

🛠️ Tools & Technologies

MySQL 8.0

MySQL Workbench

SQL (Advanced Queries)

Window Functions

Common Table Expressions (CTEs)

🗂️ Database Schema
Table: projects
Column Name	Data Type	Description
ProjectID	INT	Unique project identifier
ProjectName	VARCHAR	Name of the project
Department	VARCHAR	Department handling the project
Region	VARCHAR	Business region
Revenue	DECIMAL	Revenue generated by the project

IT

HR

Finance
across regions like North, South, East, and West.

📊 Key Business KPIs Implemented
1️⃣ Top Revenue Project per Department

Identifies the highest revenue-generating project in each department using window functions.

2️⃣ Cumulative Revenue by Region

Tracks running total revenue within each region to analyze growth trends.

3️⃣ Department-wise Revenue Contribution

Calculates percentage contribution of each department to total business revenue.

4️⃣ Project Revenue Ranking

Ranks projects within each department based on revenue performance.

5️⃣ Performance Categorization

Classifies projects as:

High Performer

Medium Performer

Low Performer

based on predefined revenue thresholds.

6️⃣ Deviation from Department Average

Measures how much each project over- or under-performs compared to its department average.
